# Kamzi Talk symbol libraries

Free AAC symbol libraries packaged for download in the [Kamzi Talk](https://github.com/Kam-Core/kamzi-talk) app (Admin › Symbols). Each folder in `packs/` is one library: `manifest.json` maps Kamzi Talk word IDs to PNG files. `packs/index.json` lists every library.

These packs are built by `scripts/symbols/` in the Kamzi Talk repo. Do not edit them by hand.
