# Kamzi Talk voices

Files used by the Kamzi Talk app to speak offline in its own voices.

- **Kokoro-82M v1.0** model and voice files (Sky, Puck, Heart, Echo): Apache License 2.0,
  by hexgrad, https://huggingface.co/hexgrad/Kokoro-82M. ONNX export from kokoro-onnx
  (MIT), https://github.com/thewh1teagle/kokoro-onnx. The model is split into parts of 24 MB.
- **Pronunciation dictionary** (lexicon-en-us.tsv): built from misaki's US English dictionaries,
  Apache License 2.0, https://github.com/hexgrad/misaki, plus Kamzi Talk's own board words.
